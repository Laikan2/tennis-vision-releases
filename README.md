# Tennis Vision Studio

Programa para Windows para receber câmeras de celular e executar a análise local de tênis.

## Instalar

Baixe o instalador para Windows em [Releases](https://github.com/Laikan2/tennis-vision-releases/releases/latest) e execute sobre a instalação anterior. Os dados, câmeras e sessões locais são preservados.

A partir da versão 0.6.0, o programa busca atualizações automaticamente. Ele baixa novas versões quando a sessão está parada e instala ao fechar. Em Configurações, use **Buscar atualização** ou **Reiniciar para atualizar** quando o download terminar.

## Aplicativo Android

O APK Tennis Vision Camera acompanha cada release. Instale o APK no Android e leia o QR mostrado pelo programa do PC para parear a câmera. As atualizações do Windows não instalam o APK no celular.

Este repositório distribui instaladores, APK e os arquivos necessários ao atualizador.
